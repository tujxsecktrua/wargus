## Overview

Wargus reimplements Warcraft II: Tides of Darkness and Beyond the Dark Portal on the open-source Stratagus engine, requiring original Warcraft II data files extracted from CD or digital release. It adds Lua scripting for custom scenarios, an improved AI opponent, modern widescreen resolutions, and cross-platform network multiplayer, breathing new life into the 1995 classic RTS.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Wargus** delivers the features you need in a clean, intuitive package.
